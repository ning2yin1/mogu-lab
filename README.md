# MOGU LAB — もぐラボ

食事・栄養・食欲・睡眠・運動・月経の関係を、個人の記録から観察する日本語PWAです。カロリー制限・体重管理・医学的な判定は行いません。

## 開発・起動

Node.js 24、Python 3を利用します。アプリ自体はビルド不要・外部依存なしです。

```sh
cd /workspace/mogu-lab
npm ci --cache /tmp/mogu-npm-cache
npm start
```

サーバーは `/workspace` をルートとして4173番で起動します。ブラウザでは `/mogu-lab/` を開きます。別の場所にクローンした場合は親ディレクトリで `python3 -m http.server 4173` を実行してください。

```sh
npm test
# サーバー起動中。システムChromiumが必要。
node tests/browser.mjs
# Chromiumのパスを変える場合：CHROMIUM_PATH=/path/to/chromium node tests/browser.mjs
```

## 使い方

- 「記録」で日付を選び、食欲・睡眠・運動を入力して保存。ハートはその日単位ですぐに保存します。
- 「JSON生成用テンプレートをコピー」をChatGPTに渡し、食事内容を付けて依頼してください。生成されたJSONを貼り付け、プレビュー後に取り込みます。
- JSONの日付が保存先です。基本は追記。同じ日付・カテゴリ・時刻・名前・食品・栄養素が一致する食事はスキップします。表記が違う重複は自動検出できないので、プレビューでも確認してください。
- 食事の「編集」は選んだ1食だけを更新。「この日の食事をすべて置き換える」は確認後、その日の食事のみを置換します。
- 履歴で過去の日を選ぶと、追加・編集・削除と栄養素詳細を利用できます。
- 分析は7/14/30/90日・全期間。食欲と栄養素、睡眠、運動、過去のハートから推定した期間を比較できます。
- 設定でJSONバックアップ・復元・全削除ができます。復元は検証と確認後に、単一のIndexedDBトランザクションで全体を置換します。

## データの意味と安全性

データはIndexedDB（`mogu-lab`、バージョン1）の `meals` / `days` に保存します。通信で送信しません。バックアップは `backupVersion: 1`、食事取り込みは `schemaVersion: 1` です。食品の値は推定値と区別して保存します。不明な栄養素はnull、既知の値だけの合計は「部分集計」。不完全な栄養素は分析グラフの対象から外します。記録していない食事の存在は判定できません。

オメガ比率は1日の合計g数から計算します。いずれかが不明な食事がある日は「データ不完全」。両方0gの日は比率・割合を表示しません。ハートが連続する日を1期間とみなしますが、記録抜けにより分類が変わり得ます。食欲未入力日は平均から除き、2日未満は平均を表示しません。因果関係や健康上の良し悪しは判定しません。

初回オンラインでService Workerのキャッシュを準備すると、オフラインで主要機能が使えます。更新時は `sw.js` のCACHE名を更新してください。更新は全タブを閉じて開き直した後に有効になり、IndexedDBは削除しません。ブラウザによるデータ削除や端末故障には備えられないため、定期的にJSONを別の場所に保管してください。

## GitHub Pages公開

1. この変更をGitHubの `main` にコミット・pushします。
2. リポジトリの Settings → Pages → Build and deployment → Source を **GitHub Actions** に設定します。
3. Actionsの `Deploy MOGU LAB` が完了すると `https://ning2yin1.github.io/mogu-lab/` に公開されます。手動のworkflow_dispatchも利用できます。
4. iPhoneのSafariで開き、共有 →「ホーム画面に追加」を選びます。

相対アセットパス、manifestの相対scope/start_url、Service Workerの配置により `/mogu-lab/` をサポートします。PWAにはHTTPS（開発時はlocalhost）が必要です。

## 検証範囲

`npm test` は欠損/0・部分集計、日次オメガ比率、不正入力、バックアップ検証、重複しない月経分類を検証します。`tests/browser.mjs` はChromiumでサブパス、320〜430pxの全画面、食事操作、日次状態、ハート同期、分析、再読み込み、バックアップ復元、オフラインを検証します。iPhone実機・Safari固有のインストール挙動と、実際のGitHub Pages公開は別途確認してください。
